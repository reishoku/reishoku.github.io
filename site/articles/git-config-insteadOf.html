GitリポジトリのURLを自動的に書き換える


          $ git config --global url.${NEWBASE}.insteadOf ${BASE}
とすると、GitのリポジトリURLに含まれる${BASE}を${NEWBASE}へ自動的に書き換えることができる。

たとえば、 


          $ git config --global url."git@github.com:".insteadOf "https://github.com/"
とすると、 https://github.com/username/repo.git が自動的に git@github.com:username/repo.git に差し変わる。
